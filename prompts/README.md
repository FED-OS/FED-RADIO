# prompts/

Working folder for the prompt scaffolding behind FED-Radio — the
conversations, templates, and reusable snippets that shaped the project and
can shape it further.

## Suggested layout

```
prompts/
├── README.md      ← this file
├── station.md     ← the 60-second "add a station" recipe as a reusable prompt
├── build.md       ← build/troubleshooting flows
└── notes/         ← raw session notes, if you keep them
```

## House rules

- Prompts are **content, not code** — they follow the repo license.
- Anything that becomes a real doc graduates into the repo root
  (see [SUMMARY.md](../SUMMARY.md) for the doc index).
- Keep secrets out (no API keys, no personal URLs beyond your own handles).
