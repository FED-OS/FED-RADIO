# discussion/

Local archive of notable GitHub Discussions threads — the ones that shaped
decisions or are worth re-reading. The live conversations happen in the
repo's Discussions tab (see `.github/DISCUSSION_WELCOME_README.md`).

## What belongs here

- Threads cited by [ADR.md](../ADR.md) or [ROADMAP.md](../ROADMAP.md)
  (archived as `YYYY-MM-DD-title.md`)
- "Ideas" threads that ended up on the roadmap, with their outcome noted
- Great questions with answers too long for the FAQ

## Format

```markdown
# <Thread title> (archived YYYY-MM-DD)
Source: <link>
Participants: <handles>

## Thread
...

## Outcome
Accepted / Rejected / Parked — see <ADR or Roadmap ref>
```

Privacy: public threads only — never archive private conversations.
