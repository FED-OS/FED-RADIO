# Support — FED-Radio

Where to get help, fastest route first.

## 1. Read the docs

Most questions are already answered:

- **Installing / the car** → [INSTALL.md](INSTALL.md)
- **Build problems** → [BUILD.md](BUILD.md)
- **"How do I…?" day-to-day** → [usage.md](usage.md)
- **Common surprises** → [FAQ.md](FAQ.md)
- **What everything is** → [SUMMARY.md](SUMMARY.md)

## 2. GitHub Discussions

For questions, ideas, and showing off your build:
**Discussions → Q&A**. Check existing threads first — the answer may already
be on air. The welcome post (`.github/DISCUSSION_WELCOME_README.md`) explains
the categories.

## 3. Issues

Bugs and concrete feature requests, using the templates
(`.github/ISSUE_TEMPLATE/`):

- **Bug report** — include device, Android version, Android Auto version, and
  logs (`adb logcat -s "FED-Radio"` is a good start; the car bridge logs under
  the tag `FED-Radio`).
- **Feature request** — remember the ground rule: features that need external
  services don't fit this project.

## 4. Security

Vulnerabilities go to the maintainers privately — see [SECURITY.md](SECURITY.md).
Never open a public issue for security problems.

## Response expectations

This is a garage project maintained in spare time: Discussions and issues are
usually answered within a few days, not hours. Maintainers are listed in
[MAINTAINERS.md](MAINTAINERS.md).

## Commercial / paid help

None — there's nothing to buy, no paid tier (see [PRICING.md](PRICING.md)).
Everything in this project is free under the [MIT license](LICENSE).
