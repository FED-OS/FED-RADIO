# Pricing — FED-Radio

## The price list

| Thing | Price |
|---|---|
| The app (all builds) | **Free** |
| Car dashboard features | Free |
| Web dashboard | Free |
| The station-ID jingle | Free |
| Source code | Free |
| Updates | Free |
| Support (community) | Free |
| Commercial use | Free (MIT license) |

There is no paid tier, no pro version, no unlock key, no subscription, no
ads, and no analytics to monetize you. There never will be — the whole
architecture was built so that nothing needs to be sold.

## Why a pricing page, then?

Because the repo carries a Ko-fi button and a `PRICING.md` in its governance
set, and "everything is free" deserved a page of its own. If the project
ever earns anything, it's a coffee at a time:

**☕ [Buy Me a Coffee at ko-fi.com](https://ko-fi.com/YOUR_USERNAME)**
*(replace `YOUR_USERNAME` in the app/footer/README with your real handle)*

Donations are optional, one-time, and change nothing about the software.

## For forks

If you fork FED-Radio and want your own tip jar: swap the Ko-fi URL in
`app/src/main/assets/index.html`, the root `index.html`, and `README.md`.
The MIT license lets you commercialize your fork however you like — this
upstream stays free forever.
