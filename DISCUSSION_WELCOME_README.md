# Welcome to FED-Radio Discussions 👋

This is the place to talk about everything FED-Radio — the in-house, scratch-built
radio app that runs on desktop, phone, tablet, and your car's Android Auto dashboard.

## Categories

- **📢 Announcements** — releases and project news
- **💡 Ideas** — proposed stations and features before they become issues
- **🛠 Show & Tell** — your builds, dashboards, car setups
- **❓ Q&A** — questions about building, sideloading, or Android Auto quirks
- **☕ Lounge** — anything else

## House rules

1. Keep it in-house: this project deliberately uses zero third-party services —
   feature requests that require external SDKs will likely be declined.
2. Be decent. Full policy in [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
3. Found a bug? Open an issue instead — it tracks better.

*Built from scratch. Broadcast from the garage.*
